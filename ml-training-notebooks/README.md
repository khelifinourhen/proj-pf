# 🔬 Data Science, Entraînement & Notebooks ML

Contient l'ensemble des scripts de prétraitement, d'entraînement des modèles non supervisés (*Isolation Forest*), d'audit des performances et les notebooks Jupyter.

## 📁 Contenu
- dataset/ : Fichier de données capteurs 200k observations.
- 	rain_and_save_pipeline.py : Script principal d'entraînement et d'export du pipeline sérialisé.
- un_final_audit.py : Script d'audit et de validation des métriques.
- 
otebooks/ : Notebooks Jupyter d'analyse exploratoire des données (EDA) et de modélisation.
