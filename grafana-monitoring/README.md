# 📊 Monitoring & Tableaux de Bord Grafana

Dashboard de visualisation en temps réel de la télémétrie capteurs, des scores d'anomalie et des alertes de maintenance prédictive.

## 📁 Contenu
- dashboard.json : Dashboard Grafana complet préconfiguré.

## ☁️ Déploiement sur Grafana Cloud (100% Gratuit)
1. Créez un compte gratuit sur [Grafana Cloud](https://grafana.com/products/cloud/) (plan Free Forever).
2. Connectez votre source de données **InfluxDB Cloud** dans **Connections > Data sources**.
3. Allez dans **Dashboards > New > Import**.
4. Importez le fichier dashboard.json.
